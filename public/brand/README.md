# YOOJIN — PNG 브랜드 에셋

선택된 1번 브랜드 보드에서 제작한 투명 배경 PNG입니다. 기존 글꼴을 이용한 SVG 재구성 대신 **원본의 세리프 모노그램·궤도·별 형태**를 사용합니다.

- `yj-horizontal-dark.png`, `yj-horizontal-light.png`: 인트로 가로형 로고 (밝은 배경 / 어두운 배경)
- `yj-monogram-dark.png`, `yj-monogram-light.png`: 챕터 헤더 소형 로고
- `yj-emblem-dark.png`, `yj-emblem-light.png`: CONTACT 장식
- `yj-favicon.png`: 브라우저 탭 아이콘

`dark`는 진한 글씨(밝은 배경용), `light`는 밝은 글씨(어두운 배경용)입니다.
